# 🏝️ 친구 배신 게임 — 배포 가이드 (따라 하기)

코딩 몰라도 괜찮아. 아래 순서대로만 하면 친구들과 같이 할 수 있는 링크가 생겨.
(처음 한 번만 30분쯤 걸리고, 그 다음부터는 링크만 보내면 돼!)

## 먼저 알아둘 것

- 이 게임은 **서버가 게임 규칙을 직접 관리**해. 그래서 점수나 아이템을 몰래 늘리는 게 안 돼.
- 데이터베이스/API 키/비밀번호는 **필요 없어**. 환경변수도 설정할 게 없어 (보안상 노출될 비밀 정보가 아예 없음).
- Vercel/Netlify는 실시간 게임 서버를 못 돌려서 **Render**(무료)를 써. Firebase/Supabase 대신 서버가 직접 동기화해서 가입할 서비스가 줄었어.
- 필요한 가입: **GitHub**(코드 보관) + **Render**(웹사이트 실행). 둘 다 무료.
- 가능하면 **컴퓨터**로 진행해줘. (태블릿/폰도 되지만 파일 올리기가 번거로워)

---

## 1단계. GitHub 가입하고 코드 올리기

1. https://github.com 접속 → **Sign up**으로 가입 (이메일 인증까지).
2. 로그인 후 오른쪽 위 **+** → **New repository**.
3. Repository name에 `friend-betray-game` 입력 → **Public** 선택 → **Create repository**.
4. 만들어진 화면에서 **uploading an existing file** 링크 클릭.
5. 내가 받은 `friend-betray-game.zip`의 압축을 풀어.
6. 압축 푼 폴더 **안의 내용물 전부**(server.js, package.json, render.yaml, README.md, public 폴더)를 GitHub 화면에 끌어다 놓기.
   - ⚠️ 폴더 자체가 아니라 **폴더 안의 파일들**을 올려야 해. `public` 폴더는 그대로 같이 올려.
   - `.gitignore` 파일은 숨김 파일이라 안 보여도 괜찮아 (없어도 작동해).
7. 아래쪽 초록색 **Commit changes** 클릭.

✅ 확인: 저장소 첫 화면에 `server.js`, `package.json`, `public` 폴더가 보이면 성공!

## 2단계. Render 가입하고 웹사이트 만들기

1. https://render.com 접속 → **Get Started** → **GitHub로 가입(Sign in with GitHub)** 선택.
2. 로그인 후 오른쪽 위 **New +** → **Web Service**.
3. **Connect a repository**에서 `friend-betray-game` 선택. (안 보이면 *Configure account*를 눌러 GitHub 저장소 접근을 허용해줘.)
4. 설정 칸을 이렇게 맞춰줘:
   - **Name**: `friend-betray-game` (원하는 이름 OK, 이게 주소가 돼)
   - **Language/Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: **Free**
5. 맨 아래 **Create Web Service** 클릭.
6. 로그가 흐르다가 `친구 배신 게임 서버 실행 중`이 보이고 위쪽에 **Live**가 뜨면 완료 (2~5분).

## 3단계. 환경변수 설정

**설정할 게 없어!** 비워두면 돼. (Render가 알아서 포트 번호를 넣어줘.)
나중에 비밀번호나 API 키가 필요한 기능을 추가하게 되면 Render의 **Environment** 메뉴에 넣고, 코드에는 절대 직접 쓰지 않으면 돼.

## 4단계. 공유 링크 만들기

1. Render 화면 왼쪽 위 이름 아래에 `https://friend-betray-game-xxxx.onrender.com` 같은 주소가 있어. 이게 **게임 링크**야.
2. 그 주소를 눌러서 게임 첫 화면(이름 입력)이 뜨는지 확인.
3. 이 주소를 카톡/문자로 친구에게 보내면 끝!

## 5단계. 방 만들고 친구 초대하기

**방장(너):**
1. 링크 접속 → 이름 입력 → **🎮 방 만들기**.
2. 화면에 큰 **방 코드**(예: K7P92)가 떠.
3. **🔗 초대 링크 복사**(또는 공유)를 눌러 친구에게 보내.
4. 친구들이 다 들어오면 **▶ 게임 시작** (2명 이상부터 가능, 최대 8명).

**친구(다른 태블릿/폰):**
1. 받은 링크를 열기 (초대 링크면 방 코드가 이미 입력돼 있어).
2. 이름 입력 → **🚪 방 참가** (코드를 직접 입력해도 돼).
3. 로비에서 친구 이름이 보이면 방장이 시작할 때까지 기다리기.

## 게임 조작

- **폰/태블릿**: 왼쪽 아래 조이스틱으로 이동, 오른쪽 아래 큰 버튼으로 채집/캠프/탑승, 위쪽 작은 버튼으로 가방·친구·캠프·미션·채팅.
- **PC**: WASD/방향키 이동, E 또는 스페이스 = 큰 버튼, I 가방, P 친구, C 캠프, M 미션, Enter 채팅.
- 친구 메뉴(👥)에서 🤝 동맹 · 🔄 거래 · 😈 배신을 쓸 수 있어.

## 꼭 알아둘 점 (무료 서버의 특징)

- Render 무료 서버는 **15분 동안 아무도 안 들어오면 잠들어.** 잠든 뒤 첫 접속은 **30~60초** 걸려. 친구들 부르기 전에 네가 먼저 링크를 열어서 깨워두면 편해.
- 서버가 재시작되면 진행 중인 방은 사라져. (게임은 약 11분이라 보통 문제없어.)
- 폰 화면이 꺼지거나 앱을 잠깐 나가도 같은 브라우저로 다시 열면 자동으로 방에 돌아와. 60초 넘게 끊기면 탈락 처리돼.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 링크가 한참 안 열림 | 잠자던 서버가 깨는 중이야. 1분 기다렸다가 새로고침 |
| Render에서 Deploy failed | 1단계에서 `package.json`이 폴더 안이 아니라 **저장소 맨 첫 화면**에 있는지 확인 |
| 화면이 하얗게 나옴 | `public` 폴더가 같이 올라갔는지 확인 |
| 방 코드가 없다고 나옴 | 코드는 5자리 영문+숫자. 서버가 재시작됐다면 새로 방 만들기 |
| 코드를 고치고 싶을 때 | GitHub에서 파일 수정 후 Commit하면 Render가 자동으로 다시 배포해 |

## (선택) 내 컴퓨터에서 먼저 테스트하기

1. https://nodejs.org 에서 Node.js(LTS) 설치.
2. 압축 푼 폴더에서 터미널을 열고 `npm install` → `npm start`.
3. 브라우저에서 `http://localhost:3000` 접속. 같은 와이파이의 폰에서는 `http://내컴퓨터IP:3000`.
